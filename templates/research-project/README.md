# 科研项目交付参考包

这是接入参考结构，不是一个已经实现的科研项目。复制到项目后填写实际信息；按原样运行结构检查应失败，不得据此展示科研能力。

1. 保留现有项目代码，复制所需模板、`research.json`、`tools/research_check.py` 和工作流。
2. 填写真实项目名、维护者、支持平台、依赖文件、安装／最小案例／验证命令。
3. 完成 `docs/` 内的运行说明、验收依据、证据、限制和许可说明。
4. 采用明确许可并加入实际 `LICENSE`。模板的 MIT 不自动成为你的项目许可。
5. 在独立环境运行 `python tools/research_check.py --root .`；确认命令内容可信后再加 `--run`。

报告区分结构、安装、最小案例、自动验证与人工科学审核。PR 工作流只在临时 GitHub runner 中运行，不接触 API 支持凭据。

进入正式项目后，将本页替换为该项目的介绍、快速开始、结果与限制以及贡献入口。项目内部相对链接应保留有效。
