# Python 科研项目参考包

这份参考包帮助整理运行环境、使用案例与检查方式。社区的项目组成要求将根据首批真实项目继续完善；已有项目可以按需取用这些文件。

## 使用步骤

1. 保留自己的代码，将需要的文档模板和工作流复制到项目。
2. 在 `research.json` 填写项目名、维护者、依赖和实际运行命令。
3. 补充运行案例、判断标准、证据、适用范围与来源说明。
4. 选择适合项目的许可，提供 `LICENSE`。
5. 执行 `python tools/research_check.py --root .`，按报告补全空白字段。
6. 在独立环境中确认命令后，加 `--run` 执行安装、小案例和验证。

复制工作流时，同时复制 `tools/research_check.py` 与 `tools/sensitive_changes.py`。参考工作流使用 Python 3.12 和 Linux；按项目实际运行条件调整。

正式项目的 README 应介绍用途、作者、快速开始和贡献入口。开发记录可以稍后补充。Skill 与其他工具可以保留适合自身的构建和测试方式。
