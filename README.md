# 参与 Shenyan-kosmoX

这里是社区的公共交流入口。可以带来一个正在思考的科学问题，也可以分享使用工具的经验、计算中的差异，或希望一起完善的项目。具体代码和研究案例在各项目仓库中推进，跨项目的方法与想法在这里相遇。

[组织主页](https://github.com/Shenyan-kosmoX) · [发起团队](ABOUT.md) · [第一次参与](START-HERE.md)

## 从已有研究开始

Floquet–Maxwell 和 EcoDynamics 围绕时空调制光子晶体与生态动力学提供数值工具、文献案例和检查方法。WeChat Content Studio 则提供文章整理、排版与个人风格管理工具。可以先选择眼下用得上的项目，再进入具体案例或 skill。

| 项目 | 可以做什么 | 提供形式 |
| --- | --- | --- |
| [Floquet–Maxwell](https://github.com/Shenyan-kosmoX/floquet-maxwell) | 计算材料调制引起的光场、增长、传播与散射变化 | 计算工具箱、Python 库 |
| [EcoDynamics](https://github.com/Shenyan-kosmoX/ecodynamics) | 分析群落稳定性、扰动放大、延迟效应与长期组装 | 计算工具箱、Python 库 |
| [WeChat Content Studio](https://github.com/Shenyan-kosmoX/wechat-content-studio) | 整理文章与图片，生成预览和富文本，管理自己的样式 | Agent skill、CLI、Python 库 |

[研究与工具目录](docs/RESEARCH.md)按领域和使用方式提供索引，连接各项目的能力、案例、安装和 skill 入口。对某个结果有疑问时，在对应项目的 Issue 附上输入、步骤和观察；跨项目的方法问题可以到社区讨论区交流。

## 准备提交工作

[贡献指南](CONTRIBUTING.md)介绍修改和提交步骤。[SORS 0.1](standards/SORS/SORS.md)约定项目说明、代码、环境、案例和结果怎样相互连接，让使用者容易找到入口，也让维护者少一些重复解释。项目可以保留自己的专业文档和目录，由一份清单连接现有材料；准备接入时，可从[项目整理说明](docs/RESEARCH-CONTRACT.md)开始。

提交后，固定脚本会帮助发现缺少的部分、失效的文件引用和未登记的环境；项目自己的测试检查软件行为，成员通过阅读与试用讨论方法和结果。清楚的反馈使贡献更容易继续完善。[了解审核过程](docs/REVIEW.md)。

愿意分享开发经历的朋友，也可以参考[开发记录](docs/DEVELOPMENT-NOTES.md)。一个方法为什么被选中，一次意外结果怎样被理解，都可能启发后来者。
