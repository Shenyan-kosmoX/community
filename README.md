# Shenyan-kosmoX · 一起开始研究

> 让个人的探索，成为后来者可以继承的能力。

这里处理跨项目的交流、研究提案、参与说明和资源支持。具体科研代码、验证结果、任务与 PR 留在相应项目仓库。

[组织主页](https://github.com/Shenyan-kosmoX) · [Manifesto](https://github.com/Shenyan-kosmoX/.github/blob/main/MANIFESTO.md) · [开始参与](START-HERE.md) · [研究目录](docs/RESEARCH.md)

## 你可以从任何一处开始

| 现在想做的事 | 去哪里 |
| --- | --- |
| 我有一个问题，还不确定怎样研究 | [讨论指引](docs/DISCUSSIONS.md) |
| 我想贡献代码、文档、验证或复现结果 | [贡献指南](CONTRIBUTING.md) |
| 我有一个项目，希望持续共同维护 | [接入说明](docs/PROJECT-INTAKE.md) |
| 我的开放研究需要模型 API 支持 | [资源支持](docs/RESOURCES.md) |

**当前状态：** [进入讨论区](https://github.com/Shenyan-kosmoX/community/discussions)。API 支持申请尚未开放，实际额度和交付渠道确认后再启用。

## 我们共同留下什么

一个项目可以从很小的案例开始。每次贡献逐渐明确：它解决什么问题、怎样运行、依据什么判断结果、有哪些限制，以及别人如何接着使用。

[科研交付约定](docs/RESEARCH-CONTRACT.md) · [审核如何工作](docs/REVIEW.md) · [成果与引用](docs/RECOGNITION.md)

## 公共协作

问题先讨论，工作明确后建立 Issue，成果通过 PR 审核。科研与工程判断分别记录；CI 的绿色状态仅表示相应检查通过。

维护与迁移说明见 [OPERATIONS](docs/OPERATIONS.md)。项目交付参考包见 [templates/research-project](templates/research-project/README.md)。参考包没有预装科研成果，也不是已经接入的研究项目。
