# 参与 Shenyan-kosmoX

这里是社区的公共交流入口。科研问题、项目提案和社区反馈在这里讨论；具体代码和研究任务在各项目仓库中推进。

[组织主页](https://github.com/Shenyan-kosmoX) · [发起团队](ABOUT.md) · [第一次参与](START-HERE.md)

## 找到你需要的入口

| 想做的事 | 直接前往 |
| --- | --- |
| 分享问题、论文或想法 | [研究讨论](https://github.com/Shenyan-kosmoX/community/discussions/new?category=general) |
| 交流方法、复现结果和工具使用 | [方法交流](https://github.com/Shenyan-kosmoX/community/discussions/new?category=q-a) |
| 提交自己的项目或工具 | [项目提案](https://github.com/Shenyan-kosmoX/community/discussions/new?category=ideas) |
| 反馈错字、坏链接或参与流程的问题 | [社区反馈](https://github.com/Shenyan-kosmoX/community/issues/new?template=community.yml) |

项目提案目前由 [@wenkuizhao261-pixel](https://github.com/wenkuizhao261-pixel) 接手。正式加入的项目放在组织仓库中，作者继续维护项目。[了解接入步骤](docs/PROJECT-INTAKE.md)。

[进入讨论区](https://github.com/Shenyan-kosmoX/community/discussions)。我们正在寻求资金支持，后续将开放免费的 API 额度申请，详情见[研究支持计划](docs/RESOURCES.md)。

## 准备提交工作

[贡献指南](CONTRIBUTING.md) 介绍修改和提交步骤，[项目整理说明](docs/RESEARCH-CONTRACT.md) 帮助作者准备代码与使用案例。想讲述开发中的经历，可以参考 [开发记录](docs/DEVELOPMENT-NOTES.md)。

提交后会进行自动检查和成员审核。遇到有争议的问题，可以在 PR 中保留不同意见，也可以转到讨论区继续交流。[了解审核过程](docs/REVIEW.md)。
