# 一项研究，可以接着做很多次

复现一篇论文，可能留下一个模型；改进模型，可能得到一套工具；另一个人带着新问题使用这套工具，又会发现新的方向。

我们希望围绕这样的长期工作组织项目，把代码、运行案例和验证方法一起留下。你可以先运行已有实验，再改一个参数、换一种方法，或提出新的问题。

## 首批项目整理中

项目公开后，这里会列出研究方向、已有结果、最小运行案例和可以参与的工作。

## 你也有一个项目？

可以先 [介绍你的项目](PROJECT-INTAKE.md)，说明正在研究什么、已经做到哪里，以及希望别人怎样参与。还在摸索方向，也可以从 [讨论](DISCUSSIONS.md) 开始。
