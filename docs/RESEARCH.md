# 我们共同建设什么

研究项目围绕持续的问题组织协作；科研能力是长期积累的对象；可版本化的研究环境是能力的重要载体。

## 当前目录

本次社区雏形尚未接入正式公开项目。已有研究将由作者选择公开范围、确认许可和运行路径后登记。这里不展示占位成果，也不把未公开的本地工作称为已经上线。

## 项目卡片的最小内容

- 项目名称、研究问题和负责人。
- 公开仓库及明确版本。
- 已有能力及其证据范围。
- 一个可运行案例和独立验证入口。
- 已知限制、维护状态和真实后续任务。

目录由 `community.json` 中经核验的项目条目生成首页链接；详细内容留在项目仓库，不在两处维护科学结论。
