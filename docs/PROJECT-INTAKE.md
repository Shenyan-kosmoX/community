# 提交项目

社区接收以 AI for Science 为主线的科研项目，也欢迎研究与创作中使用的 skill 和工具。正式加入的项目放在 Shenyan-kosmoX 的组织仓库中，由作者继续维护。

[介绍你的项目 →](https://github.com/Shenyan-kosmoX/community/discussions/new?category=ideas)

## 先介绍用途和进展

第一篇帖子写清两件事：项目想解决什么问题，目前做到哪里。已有代码、样例或研究记录可以附上；也可以说说为什么开始、需要哪些帮助，以及准备怎样继续维护。

这一步用于了解项目。运行环境、验证和许可材料可以在接入过程中逐步整理。

## 确认项目怎样加入

目前由 [@wenkuizhao261-pixel](https://github.com/wenkuizhao261-pixel) 接手提案和接入决定。沟通留在原帖子里，包括准备开放哪些内容、组织内采用哪个仓库，以及由谁维护。

作者已有仓库时，先确认转入组织或将准备公开的内容整理到组织新仓库的方式，再实际操作。接入后，项目 README 列出作者、维护联系人和贡献入口。

## 整理首个可使用的版本

我们会以首批真实项目为参考，确定一版项目需要包含哪些材料，以及上传时怎样自动检查。当前可以先准备：

- 介绍：用途、已有工作、作者和维护联系人。
- 使用案例：依赖、输入、运行步骤和输出示例。
- 检查记录：怎样判断结果、采用什么参照、还有哪些问题。
- 许可与来源：代码和材料可以怎样复用。

科研计算与内容工具采用适合各自用途的检查方法。现有 [整理说明](RESEARCH-CONTRACT.md) 和 [参考包](../templates/research-project/README.md) 可供准备时使用，正式的首轮自动检查标准将随首批项目完善。

## 发布与后续贡献

项目准备好后，在组织仓库发布，并加入 [研究目录](RESEARCH.md)。后续较小改动由内部成员审核；方法或结果有分歧时，把不同意见和依据留在 PR，必要时在讨论区继续讨论。
