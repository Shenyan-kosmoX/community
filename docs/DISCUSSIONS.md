# 聊聊你在研究什么

读到一篇有意思的论文，实验遇到一个解释不了的结果，或是想找人一起试一个方法，都可以在这里聊。

<!-- status:start -->
[到讨论区聊聊 →](https://github.com/Shenyan-kosmoX/community/discussions)
<!-- status:end -->

想直接发帖，可以选 [研究想法](https://github.com/Shenyan-kosmoX/community/discussions/new?category=general)、[方法交流](https://github.com/Shenyan-kosmoX/community/discussions/new?category=q-a) 或 [项目提案](https://github.com/Shenyan-kosmoX/community/discussions/new?category=ideas)。登录 GitHub 后即可填写。

## 分享一个想法

去 [研究问题与想法](https://github.com/Shenyan-kosmoX/community/discussions/categories/general) 分享你感兴趣的现象、文章或问题。

比如，可以这样开始：

> 我读到一种描述种群变化的方法，想试试它能否解释另一个系统。我找到了这篇参考，但不确定两个模型的假设是否相容。

贴上已有依据，再说说希望一起想清楚什么。刚接触一个领域也没有关系。

## 结果对不上，或方法用不顺

去 [方法与复现交流](https://github.com/Shenyan-kosmoX/community/discussions/categories/q-a)，说说你用了什么方法、期待看到什么，以及实际发生了什么。附上运行步骤或结果图，别人更容易跟着看。

比如：

> 我按文档运行了案例，改了网格以后结果变化很大。下面是两次配置和输出。我还没分清是设置问题，还是方法本身对这个参数敏感。

如果能缩成一个小案例，别人就更容易跟着检查。暂时做不到，也可以先把已有记录发出来。

## 想把一件事持续做下去

去 [项目提案](https://github.com/Shenyan-kosmoX/community/discussions/categories/ideas)，介绍你正在做的研究，以及希望找人一起推进的部分。可以是核对一个推导、补一个算法，也可以是把现有工具整理到别人能够使用。
