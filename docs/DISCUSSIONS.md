## 何时转为 Issue

当已有具体行动、责任范围和交付判断时，在对应项目建立 Issue 并回链讨论。讨论可以继续存在，不自动变成承诺。项目接入与资源支持分别审批。

发帖只分享你有权公开的材料。不要贴 API 密钥、未公开研究全文或他人的私人信息。依据见 [贡献指南](../CONTRIBUTING.md)。
