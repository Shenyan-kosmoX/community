# 贡献、引用与致谢

社区重视每一项实际贡献：方法、代码、验证、文档、问题定位，以及持续维护。项目应当记录参与者和完成的工作，方便使用者了解成果来自谁。

## 使用项目时怎样引用

按照项目 README 中提供的方式引用，并注明使用版本。项目发布时，作者整理姓名、项目名称、版本及仓库链接；已有 DOI 的成果也可以提供 DOI。

## 欢迎在论文中致谢

如果社区的工具、交流或资源支持帮助了你的研究，欢迎在论文中致谢 Shenyan-kosmoX，并说明具体帮助。使用了某个项目的方法或代码，也请引用项目本身与相关作者。

例如，可以按实际情况写：

> 感谢 Shenyan-kosmoX 社区提供的〔具体工具、讨论或支持〕。

示例中的内容按实际使用填写。论文作者署名由相关作者根据实际学术贡献讨论。

## 补充贡献记录

发现自己的贡献遗漏时，可以在相关项目提出 Issue 或 PR，注明工作内容和对应记录。项目维护者据此核对并补充。具体记录形式随项目整理完善。
