# 让做过的工作被看见

一项研究能继续推进，往往依靠许多不同的工作：有人提出方法，有人写代码，有人反复核对结果，也有人把文档改到第一次使用的人能看懂。

这些贡献都值得留下名字。项目的贡献说明和版本记录应当写清实际工作，而不只统计提交次数。证明一种方法暂时行不通、发现错误或长期维护一个模块，也属于贡献。

## 软件怎样引用

每个项目在发布版本时提供引用方式，包括作者提供的姓名、版本和稳定链接。有 DOI 时可以使用 DOI；没有时，仓库链接与确定版本同样能够指向实际成果。

## 论文怎样署名

论文署名由相关作者根据实际学术贡献讨论。软件贡献记录与论文作者名单可能不同；资源支持、PR 合并或审核本身也不直接决定论文署名。准备共同写论文时，尽早讨论各自承担的工作和署名安排。

## 暂停参与以后

已有贡献会继续保留。需要休息或换一个方向时，可以说明手头工作的状态；如果承担维护职责，尽量为接手的人留下一份说明。
