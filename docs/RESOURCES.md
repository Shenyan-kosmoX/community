# 研究支持计划

我们正在寻求资金支持，筹备面向社区研究者的免费模型 API 计划。希望帮助大家阅读文献、尝试模型、开发工具，推进自己的研究。

<!-- resource-status:fundraising -->

资金到位后，支持计划由公司提供资源，采用申请审核的方式。具体额度、申请入口和使用安排将在这里公布。后续也计划逐步提供计算集群支持。

现在可以先在 [讨论区](https://github.com/Shenyan-kosmoX/community/discussions/new?category=general) 介绍研究目标，以及希望借助 AI 完成的工作。项目提案见 [提交项目](PROJECT-INTAKE.md)。
