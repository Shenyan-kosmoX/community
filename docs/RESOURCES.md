# API 研究支持

## 当前状态：申请尚未开放

现阶段规划支持模型 API 额度，不表示已经提供 GPU、计算集群或无限调用。有限公共资源通过申请审核分配。正式开放前，需要确认实际可用额度、审批联系人及私下凭据交付渠道；当前不承诺额度或响应时限。

## 拟采用的申请方式

开放后通过“API 研究支持”Issue 表单申请。说明研究目标、已有项目或提案、API 用途、预计调用需求、阶段期限、准备开放的成果以及不适合公开的材料类型。不要上传那些私人材料本身。

审批关注问题是否清楚、计划是否可执行、预算是否合理、公共成果是否明确。学历和机构不是硬性资格。资源支持与项目接纳分别决定。

## 阶段支持

先支持范围明确的小阶段。续额依据实际使用、阶段证据和下一步计划决定。没有预期发现不自动构成失败；超额需求需重新说明。实际额度与有效期在批准记录中明确，不默认无限续额。

## 开放交付

接受支持前，申请者与维护者确认应开放的代码、配置、验证和结果记录，以及各自许可。不追溯要求交付既有私有资产。研究结果可以阴性或尚无定论。

## 凭据与其他数据

申请状态和非敏感决定可以公开。密钥不进入 Issues、PR、日志或仓库，只通过事先确定的私密渠道交付。使用 API 不要求将个人工作轨迹提交给社区或公司；额外用途独立授权。

## 演示

本地演练可以使用虚构额度和申请材料，但必须标明“演练、未授予资源”。不得将其计入资助成果。
