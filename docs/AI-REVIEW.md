# AI 辅助审阅 · 可选

当前为可复制的审阅协议，没有外部服务或在线机器人。选定工具后，由维护者提供允许分享的 diff、目标与证据；不得提供密钥或未授权材料。

```text
请审阅这次科研贡献，区分确定事实、推测和待核验事项。
输入：任务目标、固定条件、改动差异、运行记录、验收依据、独立参照。

逐项回答：
1. 改动试图支持哪些具体主张？
2. 运行记录能证明什么，不能证明什么？
3. 是否同时修改了 reference、容差、测试或检查器？这些修改有什么依据？
4. 是否混淆有限模型一致性、数值收敛和物理正确性？
5. 还有哪些可执行的独立控制可以区分可能的解释？

每个问题关联具体文件或证据。没有检查的数据不要声称检查过。
只给建议，不代替领域审核，不自动批准合并。
```
