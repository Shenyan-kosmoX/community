# 记录项目的开发经历

开发记录可以帮助读者理解作者为什么做这个项目，以及重要的设计选择。写其中一段经历就够了，也可以随着工作逐步补充。

可以从这些问题中选择与你有关的：

- 最初需要解决什么？当时已有的工具为什么不够用？
- 哪个设计经过了比较？为什么最后采用现在的做法？
- 与 AI 合作时，哪些工作交给了它，哪些判断由你完成？
- 使用者的反馈带来了什么修改？
- 下一步准备做什么，希望谁来参与？

有图、代码版本或讨论记录时，附上链接，读者就能继续了解。过程顺利或反复都可以照实记录，不必特意寻找转折。

文章可以放在项目仓库的 `docs/development-notes.md`，由实际作者署名，再从 README 链接过去。它可以晚于代码发布；个人经历由作者讲，团队共同决定说明参与者。
