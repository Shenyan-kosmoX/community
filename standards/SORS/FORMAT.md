# 让一个科研项目更容易被接续

SORS 项目组织指南 · v0.1

当一个人带着自己的问题打开陌生仓库时，他通常要先弄清几件事：这里已经做到了什么，能否帮助自己的研究，从哪里开始，以及遇到疑问时可以和谁讨论。材料组织得清楚，这些准备就能少花一些时间，交流也更容易围绕真正的问题展开。

SORS 希望为这样的合作提供一套共同习惯。项目仍然保留自己的研究路线、工具和目录；参与者能够用熟悉的入口找到需要的说明，也能把新的贡献放到别人找得到的位置。

## 先让读者认识你的项目

项目首页介绍关心的科学问题、已经提供的功能，以及可以查看的研究成果。已有多个模块、文献案例或计算基准时，给它们一个完整目录，让读者看见项目真正积累了什么。

快速开始可以选择一个容易运行的例子。它帮助读者熟悉工具，完整能力和案例目录则帮助读者找到更接近自己问题的工作。两者相互连接，项目的丰富内容也就容易被发现。

## 为第一次运行准备清楚的起点

说明需要什么软件、怎样安装、在哪里执行命令，以及计算前应准备哪些参数和材料。运行结束后，告诉读者去哪看图、怎样读取数据、哪些数值值得先留意。

一个项目使用多套环境时，让每个案例指向自己的说明。比如基础矩阵计算、独立全波对照和某篇文献的版本固定计算，可以共存于同一项目中。明确的入口能减少反复询问，也让维护者更容易重现使用者遇到的问题。

## 把方法和实现接起来

读者既需要知道算法怎么调用，也需要理解计算代表什么。方法说明给出模型、主要假设、变量和单位；接口或案例再连接到对应代码与配置。选择了一种有条件的方法时，解释它适合回答哪些问题。

这些内容通常已经写在论文笔记、API文档、配置或脚本中。保留一份主要说明，其他位置引用它，能够减少改动以后相互矛盾的解释。已有项目可以沿用原来的组织方式。

## 用案例呈现已经做过的研究

一个案例围绕具体问题组织模型、参数、方法和结果。读者应能从图找到数据，从数据找到配置和生成方式，再从结果回到它所回答的问题。

图和数据附上必要的阅读说明：坐标与单位、数组或表格的含义、使用的版本，以及比较时应保持哪些条件。大型数据可以独立存放，只要取得方法和版本清楚，后来者同样能够使用。

案例目录收录实际完成的工作，也可以介绍正在推进的问题。每项案例写清当前进展，方便有兴趣的人判断自己能从哪一步加入。

## 让核查结果和讨论问题有依据

研究者常常从一次不同的计算结果开始交流。提供解析参照、独立方法、验证脚本或文献比较，能够帮助双方先确认使用了相同的模型、参数和观测量。

验证说明写清检查了什么、怎样比较，以及实际得到了什么。有明确误差标准时，保留其定义与依据；需要同行判断的部分，提供相应的图、数据和解释。暂未解释的差异也可以成为值得一起研究的问题。

报告问题时，使用者能够附上运行命令、配置、环境和结果位置；维护者可以据此重现、比较和回复。与其反复补问缺少的信息，一份清楚的案例记录能让讨论更快进入实质。

## 给后续贡献留出入口

说明维护和反馈的渠道、代码与案例的分工，以及提交改进时需要检查哪些部分。小型文档修正可以轻松参与，新的科学功能则配上用途、运行例子和适当检查。

来源、引用和许可让大家知道方法从何而来、材料怎样复用，也让贡献得到恰当认可。重要方法或标准发生变化时，普通PR说明与版本记录应能帮助后来者理解差异。

项目可以分享开发故事和研究经历，作者自行选择适合公开的内容。参与规范主要帮助维护可用的成果与说明，不要求每个项目展开详细协作过程。

## 一套共同的阅读入口

| 读者想了解的事 | 项目中容易找到的位置 | 对共同维护的帮助 |
| --- | --- | --- |
| 项目研究什么、已经能做什么 | 首页、能力与案例目录 | 快速判断是否适合自己的问题 |
| 怎样亲手运行 | 安装说明、案例命令和必要材料 | 减少环境和路径上的反复沟通 |
| 方法为什么适用 | 模型、假设、参数与接口说明 | 讨论具体选择，方便扩展方法 |
| 已有哪些结果、怎样读 | 图、数据说明、配置和生成入口 | 复查、比较或重新绘图 |
| 结果怎样得到检查 | 参考方法、验证步骤与结果记录 | 共同定位差异，审阅新改动 |
| 怎样参与并接着做 | 贡献指南、问题入口、来源与许可 | 让新贡献顺利进入持续维护 |

可以将几项内容写在同一份文档中，也可以引用已有说明。项目和案例索引记录它们的位置，使导航和检查脚本能够持续工作。字段与引用细节见[技术附录](TECHNICAL-FORMAT.md)。

自动检查可以帮忙发现断链、遗漏的配置、无效命令和不一致的版本。它承担日常维护中重复而明确的工作，让社区有更多精力讨论方法和结果。[具体组成](SUBMISSION-CONTRACT.md)与[检查说明](GITHUB-CHECKS.md)可以在整理项目时对照使用。
